# Markdown everywhere

Posts are plain markdown with a little YAML frontmatter:

```markdown
---
title: My post
date: 2026-01-02
tags:
  - writing
---

Hello **world**.
```

Everything you know about markdown works: lists, tables, footnotes[^1],
smart quotes.

[^1]: Real footnotes, thanks to goldmark.
